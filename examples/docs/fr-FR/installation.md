## Installation

### pnpm

```shell
pnpm add mazey-element-ui
```

### npm

Installer Element via npm est recommandé, il fonctionne parfaitement avec [webpack](https://webpack.js.org/).

```shell
npm install mazey-element-ui
```

### CDN

Obtenez la dernière version via [unpkg.com/mazey-element-ui](https://unpkg.com/mazey-element-ui/), et importez le JavaScript et le CSS dans votre page.

```html
<!-- import du CSS -->
<link rel="stylesheet" href="https://unpkg.com/mazey-element-ui/lib/theme-chalk/index.css">
<!-- import du JavaScript -->
<script src="https://unpkg.com/mazey-element-ui/lib/index.js"></script>
```

:::tip
Il est recommandé de fixer la version d'Element lors de l'utilisation du CDN. Référez-vous à  [unpkg.com](https://unpkg.com) pour plus d'informations.
:::
