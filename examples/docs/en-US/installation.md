## Installation

### pnpm

```shell
pnpm add mazey-element-ui
```

### npm

Installing with npm is recommended and it works seamlessly with [webpack](https://webpack.js.org/).

```shell
npm install mazey-element-ui
```

### CDN

Get the latest version from [unpkg.com/mazey-element-ui](https://unpkg.com/mazey-element-ui/) , and import JavaScript and CSS file in your page.

```html
<!-- import CSS -->
<link rel="stylesheet" href="https://unpkg.com/mazey-element-ui/lib/theme-chalk/index.css">
<!-- import JavaScript -->
<script src="https://unpkg.com/mazey-element-ui/lib/index.js"></script>
```

:::tip
We recommend our users to lock Element's version when using CDN. Please refer to [unpkg.com](https://unpkg.com) for more information.
:::
